# Telecom Customer Churn Analytics Report

This project covers a comprehensive analytical workflow on telecom customer data, including:
1. Data Cleaning & Type Conversion (Handling missing values & structural anomalies)
2. Exploratory Data Analysis (EDA) using distribution metrics
3. Statistical Analysis & Groupby Segmentations (Evaluating tenure and charge dynamics)
4. Strategic Theses & Business Recommendations for reducing customer turnover
